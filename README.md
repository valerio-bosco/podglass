# podglass

AirPods Pro 2 on NixOS + Hyprland, the way they work on an iPhone: a card when you open the case,
battery for each pod and the case, automatic connection, listening mode from the bar tray, and an
edit mode to place the card anywhere.

Status: planning. Mockups: https://claude.ai/artifact/T8eXQvMCq843nEaAqUPyP8 (also `docs/mockup.html`).

- Plan for agents: `docs/PLAN.md`
- Protocol reference: `docs/PROTOCOL.md`
- UI spec: `docs/UI.md`
- Agent rules: `AGENTS.md`

Protocol knowledge comes from the LibrePods project (https://github.com/kavishdevar/librepods).
